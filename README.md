🤖 Batmeez Bot - The Rude AI Assistant

Batmeez Bot is a unique, voice-activated AI assistant with a distinct personality disorder. Unlike traditional helpful bots, Batmeez Bot is programmed to be dismissive, sarcastic, and intentionally unhelpful. It leverages advanced multimodal AI to provide realistic voice interactions that are guaranteed to hurt your feelings.

✨ Features

😡 Aggressive Persona: A custom-tuned system instruction ensures the bot never helps and always insults.

🗣️ Realistic Voice Response: Uses advanced Text-to-Speech (TTS) models for human-like, emotional (and angry) voice output.

🎙️ Live Voice Interaction: "Hold-to-Speak" functionality for seamless, walkie-talkie style conversation.

⚡ Blazing Fast: Built with Vite and React for instant load times and reactive UI.

🎨 Immersive UI: A dark, ominous interface with dynamic audio visualizers and glowing effects.

🌐 Multilingual Insults: Capable of being rude in English, Urdu, Hindi, and Hinglish.

🛠️ Tech Stack

Frontend: React (TypeScript)

Build Tool: Vite

Styling: Tailwind CSS

AI Engine: Google Gemini API (Multimodal Live/Flash)

Deployment: Vercel

🚀 Getting Started

Follow these instructions to run the project locally on your machine.

Prerequisites

Node.js (v18 or higher)

npm or yarn

Installation

Clone the repository:

git clone https://github.com/Bahawal-Ali-Official/Batmeez-Bot.git

cd Batmeez-Bot

Install dependencies:

npm install


Environment Setup:
Create a .env file in the root directory and add your API key:

GEMINI_API_KEY=your_actual_api_key_here


Run the Development Server:

npm run dev


Open your browser and visit http://localhost:3000 (or the port shown in your terminal).

📦 Deployment

This project is optimized for deployment on Vercel.

Push your code to GitHub.

Import the project in Vercel.

Important: In Vercel Project Settings > Environment Variables, add:

Key: GEMINI_API_KEY

Value: Your_Actual_API_Key

Deploy!
